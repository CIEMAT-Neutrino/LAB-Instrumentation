Instrucciones de uso

manual
  1. Comprueba que la fuente QL564TP, el generador TGP3152 y el DT2730 están conectados.
  2. Selecciona el perfil de medida y define el rango de tensiones de alimentación.
  3. Previsualiza los puntos y verifica que el conjunto de condiciones es seguro.
  4. Inicia el run; la interfaz mostrará el punto actual, el progreso y el registro en directo.
  5. Tras la adquisición, usa la sección de visualización para analizar los resultados y descargar el resumen.
